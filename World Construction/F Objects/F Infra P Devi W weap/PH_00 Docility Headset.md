# Docility Headset 
- Tech: Bridged
- Status: Prototype.
Neural interface intended for the human captain.
The headset suppresses the wearer's higher cognitive functions to a minimum, allowing the handler to exploit the subject's neural network as additional processing capacity. Events occurring during the procedure remain stored in the subject's memory, but the subject is unable to react while connected.

Originally conceived by [[CH_07]] as a means for an illithid pilot to compensate for the absence of a second illithid pilot by using the human co-pilot or captain as an auxiliary neural processor.
